# musickitjs-v3-types
TypeScript Type Declarations for [MusicKit JS V3](https://js-cdn.music.apple.com/musickit/v3/docs/index.html?path=/story/introduction--page)

## Usage
Install using
```bash
npm install --save-dev musickitjs-v3-types
```
Then, add
```js
import 'musickitjs-v3-types';
```
to every file where you need the global `MusicKit`.
You can further use
```js
import MusicKitInstance from 'musickitjs-v3-types/MusicKitInstance';
```
to get access to the `MusicKitInstance` definitions only.
